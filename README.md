# DraveKITTMobile

KITT voor je telefoon (Kivy / Android).

> 🔗 **Hoort bij elkaar:** deze telefoon-app praat met de **[KITT-Server](https://github.com/mbrv4ever/KITT-Server)** op je pc. Die server is de **motor** (het denkwerk). Installeer die eerst: [👉 Download KITT-Server](https://github.com/mbrv4ever/KITT-Server/releases/latest)

*Categorie: Mobiel · versie 1.0*

## Vanaf de broncode

Installeer Python 3.10 – 3.13 en de benodigde pakketten (zie `requirements.txt` als die er is), en start het hoofdbestand (`.py`). Eventuele `.bat`-bestanden doen dit voor je.
